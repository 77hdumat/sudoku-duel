# 스도쿠 대결 (Sudoku Duel)

AI 와 겨루는 싱글, 친구와 겨루는 멀티(최대 5명, 점령형/레이스형/아이템전, 채팅)를 지원하는 데스크톱 스도쿠.
Vite + TypeScript + three.js + Electron, 멀티는 PeerJS(WebRTC) P2P — 별도 서버 없음 (surreal-derby 와 같은 방식·TURN 워커 공유).

```bash
npm install
npm run app        # 빌드 후 데스크톱 앱 실행
npm run dist       # macOS .dmg 생성 (release/)
npm run dev        # 브라우저 개발 서버 http://localhost:5190
npm run app:dev    # (dev 서버를 띄운 상태에서) Electron 으로 핫리로드 개발
npm test           # 생성기·솔버·AI 테스트
```

## 규칙

- 9×9 판의 각 행·열·3×3 박스에 1~9 를 한 번씩. 모든 퍼즐은 해가 하나뿐이다.
- 힌트 배치는 니코리 관례대로 180° 회전 대칭. 힌트 수: 초급 ~46 · 중급 ~32 · 고급 ~26 · 지옥·변성대왕은 더 지우면 유일해가 깨질 때까지 (대칭 유지 시 보통 25~30).
- 난이도는 힌트 수가 아니라 **끝까지 푸는 데 꼭 필요한 기술**로 가른다 (`src/game/Grade.ts`, 나무위키 스도쿠/공략법 분류).
  초급 = 드러난/숨겨진 하나만 · 중급 = 교차로·부분집합 필요 · 고급 = X-윙·황새치·해파리·XY-윙·XYZ-윙 필요 · 지옥 = W-윙·핀드/사시미 X-윙·X-사슬(스카이스크레이퍼·2-String Kite)·XY-사슬 필요 (Sudoku.com 극악 수준)
  · 변성대왕 = 유일성 논법(UR·BUG+1)과 교대 추론 사슬(AIC)까지 써도 막히는 지점이 **여러 번**(어떻게 돌려도 2번 이상)인 판만 (`src/game/kingBank.json`, `npx vite-node scripts/gen-king.ts <개수> <시드>` 로 만든 판 은행을 숫자 바꾸기·돌리기·뒤집기로 변형). 맞는 판이 나올 때까지 다시 만든다
  (AIC 한두 번이면 풀리는 판은 변성대왕엔 쉽고 지옥엔 어려워서 버린다. 변성대왕 판 생성은 수백 ms 걸릴 수 있다).
  변성대왕 게임 화면에는 '추측하지 마세요' 경고가 빨갛게 깜빡인다 (`prefers-reduced-motion` 이면 깜빡임 없이).
- 정답을 넣은 칸은 잠긴다. 틀린 숫자는 빨갛게 남고 실수로 센다 (지우거나 덮어쓸 수 있음).
- **변성대왕은 채점 숨김**: 넣은 숫자가 맞았는지 바로 알려 주지 않는다 ('찍고 확인' 방지). 판을 다 채우면 채점해서 틀린 칸이 빨개지고, 그 수만큼 실수로 센다.
- 메모(N): 한 칸에 후보 숫자를 여러 개 작게 적는다. 정답을 넣으면 같은 행·열·박스의 해당 메모가 지워진다.
- 힌트(H): 한 판에 3번 (멀티는 방장이 없음/1/3/5번 중에 고른다). 고른 칸(없거나 이미 맞은 칸이면 가장 쉬운 빈칸)의 정답을 연다.
- 자동 메모(A): **지옥·변성대왕 전용** (싱글·멀티 모두). 빈칸마다 지금 놓을 수 있는 후보를 메모로 한 번에 채운다 (맞게 채운 숫자만 기준).
- 되돌리기(Z): 메모·숫자 입력을 한 단계씩 되돌린다. 맞힌 칸과 실수 수는 되돌리지 않는다.
- 풀이(E): **변성대왕 싱글 전용, 무제한** (멀티에선 없음). 다음 숫자 하나가 정해질 때까지, 쓰인 기법마다
  사람이 생각하는 순서대로 한 걸음씩(경우 나누기·사슬 따라가기·가정→모순) 글과 보드 위 애니메이션으로 보여 주고 숫자를 기입한다.
  처음 나온 기법은 **기법 카드**(나무위키 분류 등급 · 원리 · 찾는 법 · 결과 · 외우기 한 줄 · 패턴 도식)부터 보여 준다.
  풀이 중엔 그 시점의 후보가 옅게 깔린다. 사람 기술로 막히면 포싱 체인(가정 → 모순)으로 이어 간다
  (`src/game/Grade.ts` 의 `explainNext`, 기법 카드 `src/game/Techniques.ts`, 그리기 `src/ui/Explain.ts`).
- 판 크기: 9×9 / 6×6 (2×3 박스) — 싱글·멀티 모두 고를 수 있다. 6×6 은 초급·중급·고급만 (고급은 자동 메모 가능).

## 모드

**싱글** — 꼬마봇(초급) / 스도봇(중급) / 마스터봇(고급) / 지옥봇(지옥) / 변성대왕 중 하나와 같은 퍼즐로 경주. 누가 먼저 끝나도 계속 풀고 완주 시간 순으로 순위를 매긴다
(내가 먼저 끝내거나 포기하면 AI 가 지금 페이스로 끝까지 풀었을 때의 시간을 '예상' 으로 표시). AI 는 후보가 가장 적은 칸부터 채우고,
후보가 많을수록 오래 고민하며, 난이도별 확률로 틀렸다가 고친다. 조정값은 `src/game/Ai.ts` 의 `AI_PROFILES` (`sec`, `mistake`).

**멀티** (최대 5명) — 방 만들기 → 5자리 코드 전달 → 참가 → 방장이 규칙·난이도 고르고 시작. 로비·게임 중 채팅.

- **점령형**: 한 판을 모두가 같이 채운다. 먼저 맞힌 사람이 그 칸을 자기 색으로 가져가며 +1, 틀리면 -1 에 2초 입력 정지.
  판이 다 차면 점수 1위가 승리(동점이면 무승부). 판정은 방장이 한다 (`src/game/Claim.ts`). 힌트로 연 칸도 +1.
- **아이템전**: 레이스형 + 5초 안에 3연속으로 맞히면, 나를 뺀 아직 푸는 사람 전원에게 침이 날아가 1.5초 동안 판이 안 보인다 (메모는 그대로). 가려진 채로 또 맞으면 겹치지 않고 1.5초씩 늘어나고,
  맞은 사람은 랜덤 리액션("으악 더러워!!" 등 10개, `SPIT_REACTIONS`)을 외친다.
  순위표 줄마다 상대 판 미리보기가 있어 누가 맞았는지 보인다. 콤보·대상 규칙은 `src/game/Combo.ts`. 싱글에서도 '아이템전' 으로 AI 와 주고받을 수 있다.
- **레이스형**: 같은 퍼즐을 각자 푼다. 완주한 순서대로 시간이 기록되고 모두 완주·포기하면 순위 발표
  (방장은 1등이 나온 뒤 '지금 종료' 가능, 못 끝낸 사람은 채운 칸 수 순). 순위는 `src/game/Ranking.ts`.
- 모든 모드에서 실시간 순위표: 🥇🥈🥉 · 점수/진행/완주 시간 · 실수 수, 순위가 바뀌면 줄이 미끄러지며 자리를 바꾼다.
  실수는 결과에도 남는다. 점령형은 실수당 -1점, 레이스형·아이템전·싱글은 **기록 = 완주 시간 + 실수당 10초** (`MISTAKE_PENALTY_MS`).
  기록이 같으면 실수 적은 쪽이 앞선다.

**모바일** — 900px 이하는 한 줄로 쌓인다(HUD · 순위 띠 · 판 · 숫자패드 · 채팅). 터치로 칸·숫자 입력, 폰에선 배경 3D 양을 줄인다.

## 연출

- 모든 버튼은 three.js 장난감 블록 (`src/fx/Blocks.ts`): 원래 버튼은 투명하게 남아 클릭·키보드를 받고, 그 자리에 블록을 그려 글자·아이콘을 윗면에 옮긴다. 올리면 떠오르며 기울고, 누르면 눌리고, 클릭하면 통 튄다. 블록 색은 CSS 변수 `--block`. 패널·보드·입력칸은 CSS 로 같은 블록 모양
- 배경: three.js 로 떠다니는 숫자 블록·비눗방울·별·하트 100여 개 (테마별 색, 마우스 시차). 마우스가 스치면 그 근처 것만 톡 밀려났다가 스프링으로 돌아온다 (`Fx.ts` 의 `SPRING`·`DAMP`·`PUSH_RADIUS`)
- 맞히면 3D 별·하트 파티클 + 고리 + "+1"/콤보, 행·열·박스 완성 시 무지개 물결, 승리 시 색종이
- 선택 칸: 네 모서리 꺾쇠가 숨 쉬듯 움직이며 칸 사이를 미끄러진다 (메모 모드 ✎ 점선, 정지 중 ❄)
- 효과음: Web Audio 합성 (파일 없음). 우상단 🔊 로 끄고 켠다
- `prefers-reduced-motion` 이면 배경 움직임·파티클 양을 줄인다

## 조작

| 입력 | 동작 |
|---|---|
| 클릭 / 방향키 | 칸 선택 |
| 1~9 / 숫자패드 | 입력 |
| Backspace · Delete · 0 | 지우기 |
| N | 메모 모드 전환 |
| H | 힌트 |
| A | 자동 메모 |
| E | 풀이 (변성대왕 싱글) |
| Z | 되돌리기 |

src/fx/Blocks.ts    버튼 → 3D 블록
